grep
grep -i 大文字小文字区別しない
grep -n 行番号表示
grep -v 除外
grep -r recursive
grep -l ファイル名のみ
grep -c 件数だけ
grep -E 拡張正規表現

journalctl
journalctl -f リアルタイムログ
journalctl -u xxx.service サービス限定
journalctl -n 100 最新100行

find ファイル検索
sed ファイル編集 -iを入れると直接そのファイルを編集してくれる
awk テキストを「列（フィールド）」単位で処理
cut テキストから“特定の列だけ”を切り出す
uniq 連続している重複行をまとめるコマンド
xargs コマンドの「引数」に変換、実行

less -N file.txt スクロールしながら閲覧 行番号付きで見たい場合
watch：一定間隔でコマンドを繰り返し実行
wc：行数・単語数カウント
export：環境変数設定
which：コマンドの場所確認
df：ディスク使用量（全体）
du：フォルダごとの容量
env：環境変数一覧

if [ ]
for / while
